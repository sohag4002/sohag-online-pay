# 📱 Sohag Online Payment — Android Gateway App

অ্যান্ড্রয়েড ফোনের মাধ্যমে bKash, Nagad, Rocket, Upay ইত্যাদির পেমেন্ট এসএমএস রিয়েল-টাইমে রিসিভ করে সরাসরি আপনার পেমেন্ট গেটওয়ে সার্ভারে পাঠিয়ে পেমেন্ট সফল করার জন্য একটি স্বয়ংক্রিয় এবং সার্বক্ষণিক ব্যাকগ্রাউন্ড অ্যাপ্লিকেশন।

---

## 🚀 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

1. **⚡ ইনস্ট্যান্ট এসএমএস ডিটেকশন ও ফাস্ট রেসপন্স:**
   - bKash, Nagad (16167), Rocket (16216), Upay (16495), Islami Bank, Tap সহ সকল অনুমোদিত সেন্ডারের এসএমএস আসার সাথে সাথে মিলিসেকেন্ডের মধ্যে আপনার সার্ভারের `/api/add-data` এন্ডপয়েন্টে পাঠিয়ে দেয়।
   - অটো-রিট্রাই মেকানিজম: সাময়িক নেটওয়ার্ক চলে গেলেও এসএমএস ডাটাবেজে জমা থাকে এবং ইন্টারনেট আসামাত্র ব্যাকগ্রাউন্ডে পাঠিয়ে দেয়।

2. **📷 ১-ক্লিক কিউআর কোড অটো সেটআপ (Zero-Hassle Configuration):**
   - কাস্টমারকে কোনো ইউআরএল বা কী টাইপ করতে হবে না।
   - মার্চেন্ট ড্যাশবোর্ডের `Devices` পেজের **"QR কোড (Auto Setup)"** ওপেন করে অ্যাপের ক্যামেরা দিয়ে স্ক্যান করলেই ১ সেকেন্ডে সম্পূর্ণ অটো কানেক্ট হয়ে যাবে।

3. **🔄 ২৪/৭ লাইফটাইম ব্যাকগ্রাউন্ড রানিং (Phone Reboot Persistence):**
   - ফোন বন্ধ করে পুনরায় চালু (Reboot) করলেও `BOOT_COMPLETED` রিসিভারের মাধ্যমে অ্যাপ নিজে থেকেই চালু হয়ে যায়। কাস্টমার চালু করতে ভুলে গেলেও সার্ভিস চলতে থাকে।
   - স্টিকি ফোরগ্রাউন্ড সার্ভিস ও ব্যাটারি অপ্টিমাইজেশন বাইপাস (Xiaomi MIUI, Vivo, Oppo, Samsung, Realme এর জন্য অটো-স্টার্ট হেল্পার)।

4. **🧹 ৪৮ ঘণ্টার অটো ডাটা ক্লিনার (Auto Storage Pruning):**
   - অ্যাপের ডাটাবেজে ৪৮ ঘণ্টার বেশি পুরানো এসএমএস অটোমেটিক ডিলিট হয়ে যায়।
   - ফলে অ্যাপের সাইজ সর্বদা ১ মেগাবাইটের কম থাকে, কোনো মেমরি লিক হয় না এবং মোবাইল কখনোই হ্যাং বা স্লো হয় না।

5. **🎨 প্রফেশনাল ব্রান্ডেড ইউআই (Sohag Online Theme):**
   - লোগোর নেভি ব্লু (`#0B2545`) ও ক্রিমসন রেড (`#D8232A`) থিমে তৈরি আকর্ষণীয় ম্যাটেরিয়াল ৩ ডিজাইন।
   - লাইভ স্ট্যাটাস ইন্ডিকেটর (পালসিং গ্রিন ডট), মোট এসএমএস, সফল ও পেন্ডিং ট্রানজ্যাকশন কাউন্টার এবং রিয়েল-টাইম অ্যাক্টিভিটি হিস্ট্রি।

## 🛠️ অ্যান্ড্রয়েড স্টুডিও ছাড়া GitHub দিয়ে ১-ক্লিকে APK বিল্ড করার পদ্ধতি

আপনার কম্পিউটারে কোনো অ্যান্ড্রয়েড স্টুডিও বা সফটওয়্যার প্রয়োজন নেই। এই রিপোজিটরিতে **GitHub Actions CI/CD** কনফিগার করা আছে।

### ধাপ ১: GitHub-এ রিপোজিটরি তৈরি করুন
1. [github.com](https://github.com)-এ গিয়ে আপনার অ্যাকাউন্টে লগইন করুন।
2. **New Repository** তৈরি করুন (যেমন নাম দিন: `sohag-online-payment-app`) এবং রিপোজিটরিটি `Public` বা `Private` রাখুন।

### ধাপ ২: এই ফোল্ডারটি GitHub-এ পুশ করুন
আপনার কম্পিউটারের টার্মিনালে নিচের ৩টি কমান্ড রান করুন:

```bash
cd "/Users/macbook/Downloads/sohag-online-payment-android-app"
git init
git add .
git commit -m "Initial commit: Sohag Online Payment Android App"
git branch -M main
git remote add origin https://github.com/আপনার-ইউজারনেম/sohag-online-payment-app.git
git push -u origin main
```

*(আপনার-ইউজারনেম এর জায়গায় আপনার GitHub ইউজারনেম দিন)*

### ধাপ ৩: সরাসরি সাইন করা APK ডাউনলোড করুন
1. GitHub-এ আপনার রিপোজিটরির **Actions** ট্যাবে যান।
2. দেখবেন **"Build Sohag Online Payment APK"** অটোমেটিক রান হচ্ছে (২-৩ মিনিট সময় লাগবে)।
3. বিল্ড শেষ হলে:
   - **Artifacts** সেকশনে ক্লিক করে **`SohagOnlinePayment-v1.0.0-APK`** ডাউনলোড করুন (অথবা **Releases** সেকশন থেকে সরাসরি মোবাইল দিয়ে ১-ক্লিকে ডাউনলোড করে নিন)।
4. কোনো সতর্কবার্তা বা সমস্যা ছাড়াই যেকোনো অ্যান্ড্রয়েড ফোনে সরাসরি ইনস্টল করুন!
